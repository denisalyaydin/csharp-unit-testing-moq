# C# Unit Testing with NUnit & Moq

An educational project unit testing using C#, NUnit and Moq.

### NotificationApp
Unit testing a notification service using mocked repositories and notifiers.

Covered:
- Valid and invalid users
- Active/inactive users
- Invalid messages
- Exception handling
- Mock verification

### ItemManagement
Unit testing an item management service using a mocked repository.

Covered:
- Adding items
- Retrieving items
- Updating items
- Repository interaction verification

## Technologies

- C#
- .NET
- NUnit
- Moq
- Unit Testing
- Mocking
